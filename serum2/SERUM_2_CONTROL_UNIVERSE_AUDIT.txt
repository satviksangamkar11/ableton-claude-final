Each Oscillator{N} contains:
  plainParams — shared controls (mode selection, pitch, level, pan, etc.)
  WTOsc{N} — Wavetable mode container
  SampleOsc{N} — Sample mode container
  GranularOsc{N} — Granular mode container
  SpectralOsc{N} — Spectral mode container
  MultiSampleOsc{N} — Multisample mode container

MODE SELECTION FIELD:
  Oscillator{N}.plainParams.kParamType → enum value:
    kOsc_Wavetable (default, no explicit kParamType)
    kOsc_Sample
    kOsc_Granular
    kOsc_Spectral
    kOsc_MultiSample
