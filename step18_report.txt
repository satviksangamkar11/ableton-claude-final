- Resource paths bypass plainParams for file references
- This is a KNOWN EXCEPTION for resource-based parameters
- Path: varies, not in plainParams
- Reason: IR files cannot be stored in plainParams (serialization constraint)

IMPACT: None on bypass mechanism
- IRPath is a configuration/resource parameter
- Bypass mechanism operates on kParamEnable in plainParams
- Convolve bypass DOES NOT depend on IRPath
- When convolve is bypassed, plainParams.kParamEnable = 0.0 (same as all FX)

CONCLUSION: This exception is documented, expected, and does not affect
generic bypass/unbypass operations.
